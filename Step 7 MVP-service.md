## Диагностика первой попытки
Пользователь предоставил скриншот ошибки PowerShell. Команда `$env:GROQ_API_KEY = $apiCredential.GetNetworkCredential().Password` выполнилась до создания `$apiCredential`, вызвав InvokeMethodOnNull. Затем сервис сообщил об отсутствии конфигурации. Запрос генерации не был выполнен: Client проверяет переменные до HTTP-вызова.

Для повторной настройки используется последовательный ввод команд по одной строке. Ключ вводится через `Read-Host -AsSecureString`; преобразование в переменную окружения выполняется после ввода. Значение не выводится и не сохраняется в файлах. Проверка выводит только факт наличия ключа, а не сам секрет.

```powershell
$groqKeySecure = Read-Host 'Вставьте Groq API-ключ и нажмите Enter' -AsSecureString
$env:GROQ_API_KEY = ([System.Net.NetworkCredential]::new('', $groqKeySecure)).Password
$env:GROQ_MODEL = 'openai/gpt-oss-20b'
$env:LLM_TIMEOUT_SECONDS = '45'
Write-Host ('Ключ задан: ' + (-not [string]::IsNullOrWhiteSpace($env:GROQ_API_KEY)))
```

После `Ключ задан: True` повторить первый запуск из этого же окна. Код сервиса менять не требуется: причина в порядке настройки окружения. Реальная интеграция по-прежнему ожидает проверки.

## Диагностика второй попытки
На следующем скриншоте ключ задан (проверка True), сервис вернул «Нет доступа к API». В текущем клиенте это сообщение однозначно соответствует HTTP 403. Значение True доказывает только непустую переменную, но не действительность ключа или права модели. Успешная генерация не подтверждена.

Исходное сообщение клиента было слишком общим. В клиент добавлены Accept: application/json и собственный User-Agent приложения, а также безопасная диагностика HTTP: статус и ограниченное сообщение из JSON error.message. Текущий ключ, Bearer-значения и строки gsk_ скрываются. Заголовки и сырой HTML не выводятся; неструктурированный ответ помечается как возможный ответ сетевого фильтра. Причина HTTP 403 пока неизвестна, сетевой фильтр — гипотеза, не установленный факт.

Добавлены тесты JSON-диагностики с редактированием ключей и невывода HTML. Следующее действие: повторить ту же команду первого товара и изучить новое сообщение, если отказ повторится. Не менять модель, тариф или ключ без уточнения причины.

Источник трактовки HTTP-ошибок: https://console.groq.com/docs/errors .
