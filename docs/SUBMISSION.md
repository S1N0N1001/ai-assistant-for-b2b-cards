## Сопроводительное сообщение

Репозиторий: https://github.com/S1N0N1001/ai-assistant-for-b2b-cards . Реализован локальный Python CLI для подготовки B2B-карточек с Groq API, проверкой JSON, обработкой ошибок и экспортом JSON/Markdown. README представлен в MD/TXT/HTML, промпты и решения — в MD/TXT, ограничения — в MD/TXT/HTML. Проверены 27 тестов и два реальных товара.

Главное решение: свободная генерация в экспериментах добавляла неподтверждённые свойства и нарушала объём. Поэтому LLM выбирает только структуру и варианты из каталога исходных блоков, а сервис валидирует план и контролируемо собирает текст. Это ограниченная редакционная роль LLM, а не свободное сочинение технических характеристик. Подготовленные примеры — examples/outputs/product_01_selected и product_02_selected; разбор — SELECTED_REVIEW.md. Истинность исходных данных и пригодность товара окончательно проверяет человек. Для произвольных входов соблюдение объёма не гарантируется, нарушения отмечаются needs_revision. История экспериментов и возможные улучшения сохранены в документации.
