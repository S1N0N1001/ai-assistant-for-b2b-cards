## Подготовка, 02.11.2026

Оба входа проверены командой `python -m service examples/inputs/product_0X.json --validate-only`, где X — 1 или 2. Результат для каждого: valid=true, missing_fields=[]. Это структурная проверка, не сверка с паспортом и не анализ противоречий моделью.

Для будущих реальных прогонов:

```powershell
python -m service examples/inputs/product_01.json --output examples/outputs/product_01.json
python -m service examples/inputs/product_02.json --output examples/outputs/product_02.json
```

API: Groq (переход зафиксирован в шаге 6), модель openai/gpt-oss-20b. Ключ настроен в PowerShell пользователя; первый реальный вызов выполнен. Секрет недоступен процессу Codex и в проект не записан.
