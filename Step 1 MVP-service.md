# Step 1 MVP-service

Дата: 02.11.2026. Статус: выполнен.

## Цель
Проверить исходное состояние и выбрать минимальную архитектуру.

## Выполнено
- Прочитано ТЗ; рабочая папка содержит только ТЗ и локальный Git.
- Удалённый репозиторий отсутствует. Существующие пользовательские файлы сохранены.
- Выбран Python 3.12+, CLI, стандартная библиотека, Anthropic Messages API.
- Имя модели задаётся пользователем через окружение; ключи в код не попадают.
- Реализация и проверки продолжаются без ключа с подменой транспорта в тестах.

## Проверка
Python 3.12.14 доступен в bundled runtime. `git remote -v` не вернул адресов.
API-контракт сверяется с https://platform.claude.com/docs/en/api/messages и https://platform.claude.com/docs/en/api/errors.

## Зависимости
Для реального API-прогона нужны локальная настройка ключа и доступная модель. Для сдачи нужны данные двух реальных товаров и адрес размещения репозитория. Синтетические данные не заменяют их.
